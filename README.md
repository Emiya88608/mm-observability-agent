# 多模态监控诊断 Agent 原型

一个用于学习和实验的多模态监控诊断原型：读取合成监控截图和模拟指标工具结果，比较视觉语言模型、QLoRA SFT、探索性 GRPO 以及确定性后端规则的表现，并提供本地 HTTP 诊断接口。

> 当前数据和工具均为本地合成/模拟环境，不是生产监控系统。

## 系统流程

1. 生成监控截图、指标数据和训练/评测样本。
2. 使用 Qwen2.5-VL-3B-Instruct 做视觉语言基线评测。
3. 用 QLoRA 构建工具结果增强的 SFT adapter。
4. 做 OOD 测试、错误案例分析和 GRPO 奖励信号探索。
5. 通过 `query_metric_window` 本地模拟器获取指标。
6. 用后端阈值规则生成最终分类；模型生成的自然语言解释作为实验功能，不覆盖后端结论。

## 关键实验观察

- 原始 25 条合成测试中，纯 VLM 的完整 JSON 准确率为 0.44；注入工具结果后的准确率为 0.72。工具结果是预先提供的，并非模型自主完成了真实工具调用。
- 10 步 GRPO 仅为冒烟实验，不能据此声称 RL 有稳定收益。
- OOD v4 的规则与工具 API 回归通过 60 条样本；但合成标签和规则使用同一组阈值，因此这不是独立泛化评测。
- 9 条模型解释检查中，模型没有一次同时提到两项指标，并出现过与阈值相矛盾的描述。因此最终诊断由后端规则生成，模型解释不能未经验证直接作为事实展示。

## 代码目录

`src/` 包含数据生成、基线评测、QLoRA SFT、GRPO 冒烟实验、OOD 评测及 API 脚本。

- `agent_api.py`：本地确定性诊断接口。
- `agent_api_evidence.py`：返回指标、阈值、分类和建议的证据版接口。
- `agent_api_llm.py`：加载本地基础模型和 SFT adapter 生成解释的实验接口。
- `generate_dataset.py`：生成基础合成数据。
- `train_qlora.py`：QLoRA SFT 训练脚本。
- `train_grpo_smoke.py`：GRPO 冒烟训练脚本。

## 已验证环境

- Python 3.10
- PyTorch 2.6.0 + CUDA 12.4
- Transformers 4.57.6
- PEFT 0.17.1
- Accelerate 1.15.0
- bitsandbytes 0.47.0
- 单张 NVIDIA RTX 4090

模型权重、adapter、数据集和实验产物不包含在仓库中。要复现实验，需要先配置相同或兼容的依赖、模型和数据。

## 重要限制

- 评测数据是合成数据，规模较小。
- `query_metric_window` 使用本地 JSON 指标文件模拟，不连接真实监控系统。
- 阈值规则适用于当前合成数据，不可直接作为真实生产告警策略。
- 需要独立标注、与规则阈值来源不同的数据，才能评估真实泛化能力。
